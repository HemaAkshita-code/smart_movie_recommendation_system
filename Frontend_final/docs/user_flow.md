# User Journey


# New User Journey

## Stage 1: Discovery

User visits CineCompass landing page.

Actions:
- Understands platform purpose
- Learns about AI-powered recommendations
- Views featured content
- Chooses to create an account

Flow:

Landing Page
↓
Explore Features
↓
Sign Up / Login


---

# Stage 2: User Onboarding

After authentication, users complete onboarding.

Actions:
- Select favorite genres
- Choose preferred languages
- Rate sample movies
- Define viewing preferences

Flow:

Authentication
↓
Preference Collection
↓
Taste Profile Creation


---

# Stage 3: Personalized Experience

The AI system generates a personalized entertainment profile.

Actions:
- Creates Taste DNA
- Generates recommendations
- Customizes homepage

Flow:

Taste Profile
↓
AI Analysis
↓
Personalized Home


---

# Stage 4: Movie Discovery

Users explore movies through multiple channels.

Actions:
- Browse recommendations
- Search movies
- Explore genres
- View movie details

Flow:

Home / Discover / Search
↓
Movie Details
↓
AI Recommendations


---

# Stage 5: Engagement

Users interact with content.

Actions:
- Add movies to watchlist
- Rate movies
- View recommendations
- Update preferences

Flow:

Movie Interaction
↓
User Feedback
↓
Improved Recommendations
